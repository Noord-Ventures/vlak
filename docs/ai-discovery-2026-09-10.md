# AI discovery

The AI section extends the discovery setup from 7 September to the expanded component library and live assistant.

## Human navigation and search

The dedicated AI section is linked from the main navigation and the documentation rail. Its catalog renders all 47 AI references, two companion primitives, and the widget patterns guide as ordinary links before JavaScript runs. A local search field matches component names, descriptions, and familiar API aliases, including PromptInput and Code block. Keyboard users can move directly from the search field to its results; Escape restores the catalog.

Every AI reference links its Markdown contract, source, registry item, and integration guide. The indexed AI landing page and public Markdown guides link the live assistant and its source. The assistant workspace uses `noindex, follow`; private conversations and API responses are not documentation.

The route-derived sitemap contains every indexable AI page exactly once. Ordinary crawler access remains allowed. The standalone calendar fixture stays excluded from indexing.
