# Vlak starters

Small activation projects for Vlak. Each starter imports the published React package and its stylesheet, then composes a working form without adding an application framework beyond the one named by the folder.

- [`vite-react`](vite-react): client-side React with Vite.
- [`next-app`](next-app): Next.js App Router.

Run a starter from the repository root with `pnpm --dir examples/<name> install` and `pnpm --dir examples/<name> dev`.
