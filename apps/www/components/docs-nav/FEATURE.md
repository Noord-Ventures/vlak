# Docs rail

What it is, how to get there, what done looks like.

Writers: catalog groups are `packages/core/src/schema.ts` (`vlakCategories`). Face, law, and command are `apps/www/app/specimen.ts`. Numbered laws are `apps/www/app/specimen-laws.ts`. Homepage `/` and About `/about` use the same scroll-in crumb bar as docs and components: transparent at rest, paper and a 1px divider after scroll. About trail is Vlak / About.

The docs rail follows a quiet learning order: Start (Getting started, Choosing Vlak, Frameworks), Foundations (Tokens, Theming, Accessibility, Layers, StyleX), Build (Agents, Workflow kits, Project files, Safe source updates), then alphabetically ordered Domains. Workflow modernization and Built with Vlak remain linked from the global footer and keep breadcrumb labels, but sit outside this docs rail. The components rail is groups → items and remains separate from the docs order.
